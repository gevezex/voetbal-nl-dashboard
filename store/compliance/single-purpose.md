# Single purpose

**Field:** *Single purpose description* (Privacy practices → Single purpose)

## English (for the dashboard field)

```
Voetbal.nl Poule Dashboard turns a KNVB youth football pool (poule) on voetbal.nl
that the user is already viewing into a local statistics and prediction
dashboard for that pool.

The extension's single purpose is to read the standings, fixtures, results and
team selection of the pool the user selects on voetbal.nl, compute statistics
and predictions from that data, and display them in a dashboard. All processing
happens locally in the user's browser; nothing is sent to a server.
```

## Nederlands (toelichting)

De extensie heeft één doel: van de KNVB-poule die je op voetbal.nl bekijkt een
lokaal statistiek- en voorspellingsdashboard maken. Alle verwerking gebeurt in
de browser; er is geen server.
