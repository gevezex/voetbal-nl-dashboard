# Screenshots

De Chrome Web Store vereist **minimaal één** screenshot, **maximaal vijf**.

| Eis | Waarde |
| --- | --- |
| Formaat | **1280×800** (of 640×400) |
| Type | PNG of JPG |
| Aantal | 1–5 |

## Opnamelijst (aanbevolen volgorde)

1. **Overzicht** — de stand met sparklines en de komende speelronde.
2. **Poule-analyse** — bump chart + kwadrant of uitslagenmatrix.
3. **Voorspelling** — kansmatrix met 1X2 / over-under / BTTS.
4. **Scenario** — Monte Carlo-kampioenskansen en puntenwaaier.
5. **Per team** — radar + selectie (staf & spelers).

Bewaar ze hier als:

```
store/screenshots/01-overzicht.png
store/screenshots/02-poule-analyse.png
store/screenshots/03-voorspelling.png
store/screenshots/04-scenario.png
store/screenshots/05-team.png
```

## Tips

- Gebruik een schone, ingelogde voetbal.nl-sessie en een voorbeeldpoule waarop
  geen privacygevoelige of afgeschermde namen zichtbaar zijn.
- Neem het dashboard op **1280 breed** op. Met de Chrome DevTools-apparaatbalk
  (Cmd+Shift+M) stel je een viewport van 1280×800 in en maak je een screenshot.
- Zorg dat de belangrijkste grafiek helemaal in beeld staat.
